# 历史问题案例库（key_history_issue）

本目录沉淀问题分析（检视意见核查、缺陷定位、故障排查）中被接纳上库的缺陷案例，供改动前对照自查"缺陷模式与检查规则"。

## 文件命名

- 教训式文件名（一句话结论），如"枚举参数必须显式校验合法值范围.md"；
- 同类教训合并进已有案例，不重复建卡；
- 案例必须落到"文件/类/函数"级，检查规则可执行（grep/步骤）。
